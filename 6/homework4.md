## Обязательные компоненты (MUST)

*Эти компоненты являются критически необходимыми для стабильной работы системы при реальной нагрузке, обеспечивают высокую доступность, устойчивость и поддерживают real-time взаимодействие пользователей.*

| Компонент           | Обоснование                                                           | Реализация                  |
|---------------------|------------------------------------------------------------------------|------------------------------|
| Load Balancer       | Балансировка между API Gateway и микросервисами при росте нагрузки     | Yandex Load Balancer         |
| CDN                 | Быстрая отдача статики (обложки песен, фронтенд), снижение задержек    | Cloudflare + S3              |
| WebSocket Gateway   | Управление большим числом real-time соединений (важно для голосований) | EMQX / NATS JetStream        |
| CI/CD               | Автоматизация выкатываний новых версий                                 | GitLab CI/CD                 |
| Резервное копирование | Бэкапы PostgreSQL (плейлисты) и Redis (голоса, сессии)              | WAL-G + S3 Snapshots         |
| Centralized Logging | Централизованный сбор логов со всех сервисов                           | ELK Stack                    |
| Health Monitoring   | Контроль здоровья WebSocket соединений, Redis, RabbitMQ                | Custom Healthcheck + Alertmanager |

## Рекомендуемые компоненты (SHOULD)

*Эти компоненты не обязательны для первой итерации запуска, но позволяют дополнительно усиливать безопасность, наблюдаемость и устойчивость системы при росте аудитории и функционала.*

| Компонент           | Обоснование                                                                  | Реализация                      |
|---------------------|-------------------------------------------------------------------------------|-----------------------------------|
| Geo DNS             | Если проект выходит на федеральный уровень                                    | Yandex GeoDNS                    |
| Feature Flags       | Постепенный rollout новых функций (например: новый тип голосования, заказы)  | LaunchDarkly                     |
| Anti-Abuse System   | Защита от ботов, накруток и массовых заказов                                  | Cloudflare Bot Management + ML rules |
| User Behavior Analytics | Анализ поведения слушателей: популярность песен, активность            | ClickHouse + Custom Analytics    |
